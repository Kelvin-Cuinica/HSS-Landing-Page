## 📋 Sobre a Empresa

A **HSS – Herbet Security Service E.I.** é uma empresa moçambicana com **+10 anos de experiência** no mercado de segurança e automação. Oferecemos soluções completas e personalizadas para residências, escritórios, condomínios, indústrias e instituições públicas.

### Missão
Fornecer soluções inovadoras e seguras com qualidade, compromisso e profissionalismo.

### Visão
Ser referência nacional em soluções integradas de segurança e automação.

### Valores
- Responsabilidade
- Compromisso
- Profissionalismo
- Credibilidade

## 🚀 Como Visualizar Localmente

1. **Clone o repositório** (ou faça download do ZIP)

   ```bash
   git clone https://github.com/Kelvin-Cuinica/HSS-Landing-Page.git 
   ```

2. **Abra o ficheiro principal**

   ```bash
   # Basta abrir com o browser
   open index.html          # macOS
   start index.html         # Windows
   ```

> ⚠️ **Nota:** O site é 100% estático — não requer instalação de dependências ou servidor local.
