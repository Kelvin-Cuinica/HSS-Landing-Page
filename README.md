# Herbet Security Service – HSS

**Site institucional oficial**  
Soluções integradas de **segurança eletrónica**, **automação residencial** e **tecnologia inteligente** em Moçambique.

🌐 **Website ao vivo:** https://herbet-security-service.netlify.app/

## Sobre a Empresa

A **HSS – Herbet Security Service E.I.** é uma empresa moçambicana com **+10 anos de experiência** no mercado de segurança e automação. Oferecemos soluções completas e personalizadas para residências, escritórios, condomínios, indústrias e instituições públicas.

### Principais Áreas de Atuação

- Sistemas de **CCTV** (câmaras de vigilância IP e analógicas)
- **Gestão de frotas** e rastreamento veicular GPS
- **Casas e escritórios inteligentes** (automação residencial)
- **Vedações elétricas** perimetrais
- **Controlo de acessos** (biometria, cartões, tags)
- **Sistemas de alarme** e deteção de intrusão
- **Intercomunicação** e videoporteiro
- **Redes informáticas** e estruturação IT
- **Sistemas de extinção de incêndio**
- **Climatização** (instalação de ar condicionado)
- **Fabricação e automação de portões**
- **Montagem de cozinhas americanas**

## Tecnologias Utilizadas no Website

- **HTML5** + **CSS3** (Tailwind CSS v3 via CDN)
- **JavaScript** vanilla (interações leves)
- **Font Awesome** + **Boxicons** para ícones
- **Google Fonts** (Inter)
- Hospedagem estática contínua via **Netlify**

Design responsivo, otimizado para mobile e desktop, com modo dark/light (via Tailwind dark mode).

- Catálogo completo de serviços com cards interativos

- Políticas comerciais, garantias e termos claros

- Footer com links úteis e redes sociais

## Como Visualizar Localmente

1. Clone o repositório (ou faça download do ZIP)

   ```bash
   git clone https://github.com/Kelvin-Cuinica/herbet-security-service.git
   # ou apenas abra a pasta se baixou o ZIP
   ```

2. Abra o ficheiro principal

   ```bash
   # Basta abrir com o browser
   open index.html
   # ou
   start index.html    # Windows
   ```

Não é necessário instalar nada — o site é 100% estático.
